> An open-curriculum interactive digital textbook and knowledge platform exploring the convergence of Artificial Intelligence, Physical Embodiment, Kinematics, and Humanoid Robotics engineering.

---

## 📚 Curriculum Structure

1. **Foundations of Physical AI:** Embodied cognition, perception-action loops, and real-time sensory processing.
2. **Humanoid Kinematics & Dynamics:** Forward/inverse kinematics, center of mass, and bipedal locomotion.
3. **Sensors & Actuation:** IMUs, LiDAR, computer vision, motor controllers, and torque sensing.
4. **Simulation to Reality (Sim2Real):** Digital twins, physics engines, Isaac Sim, and transfer learning.
5. **Agentic & Cognitive Control:** LLM-guided high-level decision making and ROS 2 middleware integration.

---

## 🛠️ Technology Stack

- **Documentation Engine:** Docusaurus v3
- **Frontend Core:** React, TypeScript
- **Content Format:** MDX (Markdown with embedded React components)
- **Search & Indexing:** Algolia / Local Search integration

---

## 🚀 Setup & Run Locally

```bash
# Clone the repository
git clone https://github.com/mesumali-dev/physical-ai-humanoid-robotics-textbook.git
cd physical-ai-humanoid-robotics-textbook

# Install dependencies
npm install  # or yarn

# Start local documentation server
npm run start
```
